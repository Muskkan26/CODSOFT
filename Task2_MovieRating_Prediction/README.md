# Task 2 - Movie Rating Prediction 🎬

This is Task 2 of the CODSOFT Data Science Internship.

## 📁 Dataset
- *IMDb Movies India.csv*  
  The dataset contains:
  - Movie Name
  - Year
  - Duration
  - Genre
  - Rating
  - Votes
  - Director
  - Actor 1, 2, 3

## 📊 Goal
Predict the movie rating based on various features such as duration, genre, and cast.

## 📌 Files Included
- movie_rating.py — Python script for loading data, cleaning, feature selection, model training and evaluation.
- IMDb Movies India.csv — Dataset used for training the model.
- output.txt — Output and evaluation results saved from the script.

## 📈 Model Used
- Random Forest Regressor (Scikit-learn)

## 📌 Output
Accuracy metrics and predictions are saved to output.txt.
