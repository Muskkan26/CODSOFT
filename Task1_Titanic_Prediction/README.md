# Titanic Survival Prediction

This is *Task 1* of the CODSOFT Data Science Internship.

## 🎯 Objective
To build a machine learning model that predicts whether a passenger on the Titanic survived based on features such as age, sex, class, etc.

## 📂 Dataset
- *File:* titanic.csv
- *Source:* Titanic dataset (Kaggle or CODSOFT-provided)
- *Columns Used:* PassengerId, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, Embarked, Survived

## 🛠 Technologies Used
- Python
- Pandas
- Scikit-learn
- NumPy
- Matplotlib / Seaborn (optional for visualization)

## 📊 ML Model
- Used: Logistic Regression
- Evaluation Metric: Accuracy Score, Confusion Matrix

## 📁 Files Included
- titanic_prediction.py: Main prediction script
- titanic.csv: Dataset used
- output.txt: Model predictions or evaluation results

## 🔍 Output
- Predicts whether each passenger survived.
- Shows model performance and accuracy.
